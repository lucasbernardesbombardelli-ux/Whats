# Extensão: Gerador de IA de Vendas para WhatsApp

Este projeto agora inclui uma extensão prática em Python para gerar automaticamente um sistema de atendimento comercial com foco em conversão.

## Como usar

```bash
python3 gerador_extensao.py
```

Informe um nicho, por exemplo:
- `vidraceiro que vende box de banheiro`
- `clínica estética`
- `loja de roupas femininas`
- `empresa de energia solar`

A saída inclui:
- Identidade
- Estratégia
- Regras
- Inteligência
- Prompt Final pronto para uso
